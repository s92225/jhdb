# 人在江湖資料庫：品牌與功能配色

品牌主體保留墨綠 `#0d2a1c`、紙白 `#f7f7f7`、灰綠，以及首頁搜尋的黃。攻略不是宣傳頁：地圖、條件、目標和獎勵需要快速辨識，不能把所有資訊都收成近似的灰綠。

## 功能色

CSS tokens 統一放在 `app/globals.css`；不要在每個 component 自訂一套。

| 語義 | 標記色 | 深色文字 | 淺底 | 用途 |
| --- | --- | --- | --- | --- |
| 資訊 / 入口 | `#1d63ad` | `#154b83` | `#eaf3ff` | 迷宮入口、接取方式、副本入口 |
| 留意 / 路線 / 回報 | `#a56805` | `#805000` | `#fff5d6` | 途經格、方向步驟、獎勵、掉落、關鍵機制 |
| 門檻 / 挑戰目標 | `#bc4537` | `#94372d` | `#fff0ed` | 強者、轉生條件、任務門檻、BOSS |
| 流程 / 完成 / 離開 | `#157456` | `#10583f` | `#e8f6ed` | 流程、迷宮出口 |

## 使用原則

- 導覽、標題、普通正文仍以品牌墨綠為主；功能色不取代整個品牌。
- 同一概念在不同攻略用同一顏色，不能為了排版交替換色。
- 色彩只輔助辨識：一定保留「入口」「途經」「強者」「出口」、章節標題及原有數字。
- 圖例與地圖共用 `data-maze-tone` 的 CSS variables，避免兩者各自定色而漂移。
- 路線、地圖的數字與原圖排列保留；不可將傳送目的格誤畫成相鄰格。
- 正文對比最少 4.5:1，功能邊線對比最少 3:1；`npm run test:guides` 有回歸檢查。
- 淺色只作重點區塊底色，鮮明色用於邊線、圖例和方向；不把整頁背景染成彩色。
