# JHDB 江湖插畫系列

Four original AI-assisted ink-wash illustrations generated for this homepage redesign on 2026-10-31: hero, scrolls, ferry, night. User references informed art direction only; none of the attached reference files are redistributed. The generated originals remain in Codex generated_images; these project copies are WebP-encoded without creative retouching.

These atmospheric illustrations do not depict actual game screens or verify any in-game scene. Visible credit is in the homepage footer's 插畫與字體來源 disclosure.

The shipped assets are the original hero and three catalogue thumbnails.
`hero-cleanplate-preview.webp` is an AI-assisted hidden clean plate generated
on 2026-11-05 to support masked cloth/bird motion. It does not replace the
original hero. Static, reduced-motion and unsupported-WebGL views retain the
original artwork.
